# STM32_Project

STM32 Keil 工程集合：2026 年 6–9 月的学习与实验记录（STM32F103，Keil MDK）。

## 工程分类

- **串口通信**：SerialAdv_Full、SerialCmd_Test、SerialCtrl_Full、SerialCtrl_Std、SerialPanel
- **中断与定时**：EXTI_Control、EXTI_Key、SysTick_EXTI_Test、SysTick_Tick、TickBlink、TickIrq_Demo、DWT_Delay、CoreDelay
- **按键与显示**：KeyScan_Demo、KeyPress_Test、KeyOled_Full
- **传感器**：AdcTemp_Full（ADC 测温）、IrAvoid_Full（红外避障）、RadarFlash_Full、RadarRemote_Full（超声波测距）
- **存储**：FlashRW_Full
- **LED**：FlowingLight、LedPattern、Task1_LED、Task2、Task2_KeyRGB、Task3、Task4
- **模板与时钟**：StdLib_Template、StdLib_Task3、StdLib_Task_HSIClock、Task_HSIClock2、Reg_Task2_LED、Reg_Task3_Key

`_归档` 是旧版工程归档，`docs` 是相关文档。

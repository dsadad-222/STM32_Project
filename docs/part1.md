# 场景和流程

### 系统组成

本工程由上位机与下位机两部分组成，两者之间通过 USB 转串口连接。

| 组成 | 实现 | 说明 |
| --- | --- | --- |
| 上位机 | PC + 串口助手 | 按 115200-8-N-1 打开虚拟串口，手工或脚本下发协议帧 |
| 通信链路 | CH340 USB 转串口 | 接到 MCU 的 USART1（PA9 = TX，PA10 = RX） |
| 下位机 | YB-DSF01-V1.0 开发板（STM32F103ZET6） | 解析协议帧，控制外设、刷新 OLED、读写内部 Flash |
| 执行与显示 | 板载外设 | LED1、LED2、RGB 灯条、有源蜂鸣器、0.86 寸 OLED |

### 分层设计

| 层次 | 目录 | 职责 |
| --- | --- | --- |
| 应用层 | App_User | 初始化、协议解析、命令分发、状态维护、显示刷新 |
| 驱动层 | Drv_Common | 把外设细节封装成函数接口，向上屏蔽寄存器操作 |
| 库层 | STM32_Library、Arm_Kernel | STM32F10x 标准外设库 V3.6 与 CMSIS 内核文件 |
| 启动层 | Startup | 中断向量表、复位入口、栈顶定义 |

应用层不直接操作任何寄存器，全部通过驱动层接口完成。

### 模块设计

| 模块 | 源文件 | 主要职责 | 使用引脚 |
| --- | --- | --- | --- |
| 串口通信模块 | usart_drv.c / .h | USART1 初始化、中断收字节、环形缓冲、字节与字符串发送 | PA9、PA10 |
| LED 与 RGB 模块 | led_drv.c / .h | LED1、LED2 与 RGB 灯条的开关和翻转 | PG14、PG15、PG0、PG1、PG2 |
| 蜂鸣器模块 | beep_drv.c / .h | 有源蜂鸣器的鸣叫与定时鸣叫 | PG12 |
| OLED 显示模块 | oled_drv.c / .h | SSD1306 初始化、显存管理、字符与字符串显示 | PB6、PB7 |

| 数据存储模块 | flash_drv.c / .h | 内部 Flash 数据页擦写、记录校验与回读 | 无 |
| 系统时基模块 | systick_drv.c / .h | 1ms 系统节拍、毫秒延时、运行时间统计 | 无 |

# 模块(组件)及接口说明

### 模块调用说明

工程上电后按固定顺序初始化，各模块之间除调用顺序外没有其他隐含依赖。

LED_Init();  // 板载 LED1、LED2

RGB_Init();  // RGB 灯条

Beep_Init();  // 有源蜂鸣器

SysTick_Init();  // 1ms 时基，供闪烁与帧超时使用

OLED_Init();  // OLED 上电初始化并清屏

Usart_Init(USART_BAUD_DEFAULT);  // USART1，115200-8-N-1

主循环采用中断收加主循环处理的结构。串口接收全部在 USART1_IRQHandler 里完成，中断只负责把收到的字节塞进环形缓冲，不做任何耗时操作；主循环不断把缓冲里的字节取出来喂给协议解析器，再顺带服务一次转向灯闪烁。这样既不会被长数据帧阻塞，也不会漏字节。

while (1) { while (Usart_ReadByte(&rxByte) != 0) { ParseByte(rxByte); } TurnSignalService(); }

#### 3.1.1 协议帧格式

| 字段 | 字节数 | 取值 | 说明 |
| --- | --- | --- | --- |
| 帧头 0 | 1 | 0x55 | 固定 |
| 帧头 1 | 1 | 0xFF | 固定 |
| 数据域长度 | 1 | N | 功能字加数据的总字节数 |
| 功能字 | 1 | 见 3.1.2 | 决定本帧要做什么 |
| 数据 | N-1 | 见 3.1.2 | 控制单元、ASCII 文本或存储操作码 |

数据域后面允许再跟校验字节。解析器收满本帧所需参数就立刻执行，多出来的字节被忽略，因此发不发校验字节都能正常执行。帧内相邻两字节间隔超过 200ms 视为半截帧，直接丢弃并重新等待帧头。

#### 3.1.2 功能字与命令示例

| 功能字 | 含义 | 数据域 | 示例帧 |
| --- | --- | --- | --- |
| 0x06 | 控制设备 | 1 字节控制单元 | 55 FF 03 06 00 左转向灯开或关 |
| 0x07 | 下发文本 | ASCII 文本，最多 32 字符 | 55 FF 06 07 HELLO 屏显并保存 |
| 0x08 | 存储操作 | 1 字节操作码 | 55 FF 02 08 02 从 Flash 重新读回 |

控制单元取值如下：

| 控制单元 | 设备 | 引脚 |
| --- | --- | --- |
| 0x00 | 左转向灯（LED1） | PG14 |
| 0x01 | 右转向灯（LED2） | PG15 |
| 0x02 | 蜂鸣器 | PG12 |
| 0x03 | LED 灯（RGB 灯条） | PG0、PG1、PG2 |

存储操作码取值如下：

| 操作码 | 含义 |
| --- | --- |
| 0x00 | 立刻把当前状态与文本写入 Flash |
| 0x01 | 清除 Flash 记录 |
| 0x02 | 重新从 Flash 读回并恢复 |

每收到一条控制命令，对应设备做一次开与关的翻转；转向灯打开后以 500ms 为半周期闪烁。状态变化会一并写入 Flash，下次上电自动恢复。

#### 3.1.3 状态上报

每次命令执行完成，下位机通过串口回一行状态，方便在串口助手里直接核对：

STATUS  LEFT_TURN=1  RIGHT_TURN=0  BEEP=0  LED=1
